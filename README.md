# Presentación Software (Etapa 1) — HTML con CSS Flexbox Embebido

Segunda etapa de una demostración académica en tres fases sobre diseño web con **HTML5 y CSS Flexbox** para **Ingeniería en Telecomunicaciones (Team 7)**. Sobre la estructura base de la Etapa 0, esta versión incorpora un bloque `<style>` interno con tema oscuro, distribución responsiva en tarjetas mediante Flexbox y transiciones `:hover`.

## Conceptos aplicados

- Contenedor **CSS Flexbox** (`.container`) con `display: flex`, `justify-content: center`, `gap: 24px` y `flex-wrap: wrap` para adaptabilidad a distintos anchos de pantalla.
- Tarjetas interactivas (`.item`) con fondo degradado oscuro, bordes azules, sombras y efecto de elevación en `:hover`.
- Presentación de tres áreas de la carrera: **Networks**, **Wireless Communication** y **Signal Processing**.
